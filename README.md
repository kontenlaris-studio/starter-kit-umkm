# Starter Kit UMKM Digital

Satu paket untuk mendigitalkan toko kecil: **InvoiceKit offline** (generator invoice 1 file HTML) + **4 workflow n8n** (catat order, pengingat bayar, rekap harian, balas lead) + **5 template spreadsheet** (kas, stok, harga, rekap, piutang) + panduan mulai 5 hari.

**Landing:** https://kontenlaris-studio.github.io/starter-kit-umkm/ · **Beli (Rp249.000):** via Lynk (tautan di landing). Komponennya juga dijual terpisah: [paket n8n](https://kontenlaris-studio.github.io/n8n-umkm-pack/) dan [InvoiceKit web gratis](https://kontenlaris-studio.github.io/invoicekit/).
